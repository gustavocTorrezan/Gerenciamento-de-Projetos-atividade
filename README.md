# InstaCC

Este repositorio abriga o desenvolvimento de um clone funcional do Instagram construido como projeto do 1o ano de Ciencia da Computacao. 

## O que a nossa aplicacao faz:
- Autenticacao Real: Sistema de login validando credenciais de usuarios direto no back-end.
- Feed Dinamico: Listagem de postagens, gerenciamento de curtidas e sistema de comentarios integrados ao servidor.
- Direct Message (DM): Bate-papo estruturado para troca de mensagens diretas entre os usuarios cadastrados.
- Perfil Dinamico: Exibicao personalizada das informacoes e publicacoes do usuario autenticado na sessao.
